
# Module 0 — Fourier prerequisites

## 0.1 What is a signal?

For this course, think of a signal simply as a function whose independent variable is usually time:

[  
x(t)  
]

Examples could be voltage from a microphone, displacement of a vibrating string, temperature at a point, ECG voltage, or mathematically just some waveform drawn on a graph.

The important thing is that **the graph contains information**.

For example,
$$  
x(t)=3\cos(2t)  
$$

means that the signal oscillates between (+3) and (-3).

Here:

[  
A=3  
]

is amplitude, while

[  
\omega=2\ \text{rad/s}  
]

is angular frequency.

---

# 0.2 Periodic vs aperiodic

A signal is periodic if some positive (T) exists such that

[  
\boxed{x(t+T)=x(t)}  
]

for every (t).

Meaning: wait (T) seconds and you see **exactly the same signal again**.

For

[  
x(t)=\cos(2t)  
]

we know cosine completes one revolution when its angle increases by (2\pi).

So:

[  
2T=2\pi  
]

therefore

[  
\boxed{T=\pi}  
]

seconds.

An **aperiodic** signal never exactly repeats.

This distinction later becomes fundamental:

[  
\text{Periodic}\rightarrow\text{Fourier Series}  
]

while

[  
\text{Aperiodic}\rightarrow\text{Fourier Transform}.  
]

That transition is exactly how Lecture 7 introduces Fourier transform.

---

# 0.3 Period, ordinary frequency and angular frequency

There are three closely related quantities.

If the period is (T),

[  
\boxed{f=\frac1T}  
]

where (f) is measured in **Hz = cycles/second**.

Angular frequency is

[  
\boxed{\omega=2\pi f=\frac{2\pi}{T}}  
]

and is measured in rad/s.

So:

[  
T \longleftrightarrow f \longleftrightarrow \omega  
]

are just three ways of describing how fast something repeats.

For example, suppose

[  
T=0.25\text{ s}.  
]

Then

[  
f=\frac1{0.25}=4\text{ Hz}  
]

and

[  
\omega=2\pi(4)=8\pi\text{ rad/s}.  
]

---

# 0.4 Fundamental period and fundamental frequency

This becomes very important in Fourier Series.

Suppose

[  
x(t)=\cos(2t)+\sin(3t).  
]

The first wave has

[  
\omega_1=2  
]

so

[  
T_1=\frac{2\pi}{2}=\pi.  
]

The second has

[  
\omega_2=3  
]

so

[  
T_2=\frac{2\pi}{3}.  
]

We need the smallest time after which **both waves have simultaneously completed an integer number of cycles**.

Here that is

[  
T_0=2\pi.  
]

Therefore

[  
\boxed{\omega_0=\frac{2\pi}{T_0}=1}.  
]

Now notice something important:

[  
2=2\omega_0  
]

and

[  
3=3\omega_0.  
]

So our signal contains the second and third harmonics of a fundamental frequency (\omega_0=1).

This is exactly the idea behind the bell example in your lecture: different repeating patterns combine into a larger common period, and therefore their frequencies become integer multiples of one common fundamental frequency.

---

# 0.5 Harmonics

For a periodic signal with fundamental frequency

[  
\omega_0=\frac{2\pi}{T},  
]

the Fourier frequencies are

[  
\boxed{k\omega_0}  
]

where

[  
k=0,\pm1,\pm2,\pm3,\ldots  
]

So we get

[  
\ldots,-3\omega_0,-2\omega_0,-\omega_0,0,  
\omega_0,2\omega_0,3\omega_0,\ldots  
]

Lecture 5 explicitly calls these the allowed Fourier building blocks.

Usually:

[  
\omega_0  
]

is the **fundamental**, while

[  
2\omega_0,;3\omega_0,\ldots  
]

are higher harmonics.

For now, mentally think:

> harmonic number (k) tells me **which frequency slot** I am talking about.

Later (a_k) will tell us **how much signal is sitting in that slot**.

---

# 0.6 Amplitude, frequency and phase are different things

Consider

[  
x(t)=A\cos(\omega t+\phi).  
]

There are three independent ideas here.

(A) controls **how large** the oscillation is.

[  
\omega  
]

controls **how fast** it oscillates.

And

[  
\phi  
]

controls **where in its cycle it starts**.

For example,

[  
\cos t  
]

and

[  
\cos\left(t+\frac{\pi}{2}\right)  
]

have exactly the same amplitude and frequency.

Only their phase differs.

This becomes extremely important later because a **time shift often changes Fourier phase without changing Fourier magnitude**.

---

# 0.7 Why complex numbers suddenly appear

Fourier theory heavily uses

[  
e^{j\theta}.  
]

Euler's formula says

[  
\boxed{e^{j\theta}=\cos\theta+j\sin\theta}.  
]

Therefore

# [  
e^{-j\theta}

\cos\theta-j\sin\theta.  
]

Add them:

[  
e^{j\theta}+e^{-j\theta}=2\cos\theta  
]

so

[  
\boxed{  
\cos\theta=  
\frac12e^{j\theta}  
+  
\frac12e^{-j\theta}  
}  
]

and subtract:

[  
e^{j\theta}-e^{-j\theta}=2j\sin\theta  
]

therefore

[  
\boxed{  
\sin\theta=  
\frac{1}{2j}  
\left(e^{j\theta}-e^{-j\theta}\right)  
}.  
]

Lecture 5 explicitly introduces complex exponentials as a convenient object that packages sine and cosine together.

This is not just algebraic decoration. It makes Fourier manipulation dramatically cleaner.

---

# 0.8 What does (e^{j\omega t}) actually look like?

Unlike (\cos(\omega t)), it is not simply moving up and down.

Think of

[  
e^{j\omega t}  
]

as a vector rotating around the complex plane.

Its magnitude is always

[  
|e^{j\omega t}|=1.  
]

Its angle is

[  
\omega t.  
]

As (t) increases, the angle keeps increasing.

So if

[  
\omega>0,  
]

it rotates one direction.

If

[  
\omega<0,  
]

it rotates the opposite direction.

That gives physical meaning to **positive and negative frequencies**.

---

# 0.9 Why does a cosine have a positive and a negative frequency?

Take

[  
\cos(\omega_0t).  
]

Using Euler,

# [  
\boxed{  
\cos(\omega_0t)

\frac12e^{j\omega_0t}  
+  
\frac12e^{-j\omega_0t}  
}  
]

So Fourier representation says:

[  
+\omega_0:\quad \frac12  
]

and

[  
-\omega_0:\quad \frac12.  
]

Graphically:

```text
coefficient
    |
1/2 |      ↑               ↑
    |      |               |
----+------+-------+-------+------ frequency
         -ω₀       0      +ω₀
```

That exact two-line interpretation is shown in Lecture 5.

This is one of the first conceptual obstacles in Fourier analysis:

> Negative frequency does **not** mean some physically impossible negative vibration rate.

It represents the opposite direction of complex rotation.

For real-valued signals, the positive and negative complex components work together to produce ordinary real sinusoids.

---

# 0.10 What is zero frequency?

Take

[  
e^{j0t}=1.  
]

It doesn't oscillate.

So (0) frequency simply means the **constant/DC component** of the signal.

For example,

[  
x(t)=3+\cos(2t)  
]

contains a constant component of (3).

Later that becomes the Fourier coefficient

[  
a_0.  
]

And (a_0) turns out to equal the **average value of the signal over one period**. Your lecture derives exactly this interpretation.

---

# 0.11 Piecewise signals

A lot of CT problems won't give you nice formulas like

[  
x(t)=\cos t.  
]

Instead, you'll get graphs.

For example:

[  
x(t)=  
\begin{cases}  
1,&|t|<T_1\  
0,&T_1<|t|<T/2  
\end{cases}  
]

repeated every (T).

That is a periodic rectangular pulse train.

You need to learn to switch between these three representations:

[  
\boxed{\text{graph}}  
\longleftrightarrow  
\boxed{\text{piecewise equation}}  
\longleftrightarrow  
\boxed{\text{Fourier representation}}.  
]

That skill will matter much more than memorizing isolated formulas.

---

# 0.12 Unit step (u(t))

Basic definition:

[  
u(t)=  
\begin{cases}  
0,&t<0\  
1,&t>0  
\end{cases}  
]

It is useful for describing signals that start at some time.

For example,

[  
e^{-t}u(t)  
]

means:

[  
x(t)=0,\qquad t<0  
]

and

[  
x(t)=e^{-t},\qquad t>0.  
]

You'll encounter exactly this signal in the Fourier-transform part of your classwork.

---

# 0.13 Dirac impulse (\delta(t))

For now remember only the fundamental picture.

[  
\delta(t)  
]

is zero everywhere except at (t=0), but its total area is

[  
\boxed{1}.  
]

Its most useful property is

# [  
\boxed{  
\int_{-\infty}^{\infty}  
x(t)\delta(t-a),dt

x(a)  
}  
]

called the **sifting property**.

In simple language:

> the impulse picks out the value of the function exactly where the impulse occurs.

Your Fourier Series lecture later uses this directly for impulse trains.

Don't worry about its deeper mathematical definition yet. We have an entire later module for it.

---

# So what should you retain from Module 0?

These are the important connections:

[  
T  
\longrightarrow  
\omega_0=\frac{2\pi}{T}  
]

then

[  
\omega_0  
\longrightarrow  
k\omega_0  
]

then

[  
k\omega_0  
\longrightarrow  
e^{jk\omega_0t}.  
]

And Fourier Series will eventually say

# [  
\boxed{  
x(t)

\sum_{k=-\infty}^{\infty}  
a_ke^{jk\omega_0t}  
}.  
]

So Module 0 basically taught us what every symbol in that equation means.

Now the interesting part starts.

# Module 1 — What Fourier Series actually means

Forget the formula temporarily.

Suppose I give you this:

```text
x(t)

       /\       __
      /  \__   /  \__
_____/      \_/       \____
```

It's periodic, but ugly.

You could study this waveform directly.

Fourier's idea instead is:

> Don't ask, “What weird shape is this?”
> 
> Ask, “Which simple frequencies were mixed together to create it?”

That change of viewpoint is the entire subject.

Lecture 5 introduces Fourier Series exactly this way: a complicated periodic waveform is broken into simple sinusoidal waves.

---

# 1.1 Imagine sound first

Suppose three tuning forks are ringing simultaneously:

[  
100\text{ Hz},\quad 200\text{ Hz},\quad 500\text{ Hz}.  
]

A microphone records **one complicated waveform**.

In the time domain you may see:

```text
amplitude
   |
   | /\/\__/\/\/\_/\/\__
---+---------------------- time
```

Looking at that shape, it is not obvious that three tones exist.

But Fourier analysis says:

> Let's measure how much (100), (200), (300), (400), (500), … Hz exists.

The frequency-domain representation might look like:

```text
strength
   |
   |     ↑
   |     |      ↑
   |     |      |                 ↑
---+-----+------+-----------------+---- frequency
       100    200               500
```

Now suddenly the structure is obvious.

Same signal.

Different representation.

---

# 1.2 Time domain asks “when”; frequency domain asks “what frequencies”

In the **time domain**, the horizontal axis is time:

[  
t.  
]

You ask questions like:

- what is the signal value at (t=2)?
    
- when does it jump?
    
- how fast does it decay?
    
- where is the pulse?
    

In the **frequency domain**, the horizontal axis is frequency:

[  
\omega.  
]

You ask:

- what frequencies exist?
    
- which frequency is strongest?
    
- is high-frequency noise present?
    
- where is the dominant vibration?
    
- how much DC exists?
    

Neither representation is more “real”.

They are two descriptions of the same signal.

---

# 1.3 A useful analogy: ingredients

Suppose a smoothie contains:

[  
50%\text{ banana}  
+  
30%\text{ strawberry}  
+  
20%\text{ milk}.  
]

The smoothie itself is the time-domain signal.

The ingredient list is like the frequency-domain representation.

Fourier Series is essentially saying:

# [  
\boxed{  
\text{signal}

\text{amount of frequency 0}  
+  
\text{amount of frequency }\omega_0  
+  
\text{amount of frequency }2\omega_0  
+\cdots  
}  
]

The numbers specifying those amounts are the Fourier coefficients.

Later:

[  
a_k  
]

will be the amount corresponding to frequency

[  
k\omega_0.  
]

Lecture 5 explicitly describes (a_k) this way: it indicates how much of the (k)-th frequency exists in the signal.

---

# 1.4 But how can simple sinusoids create sharp corners?

This is initially unintuitive.

A sine wave is smooth:

```text
~~~~~~
```

A square wave has sharp jumps:

```text
 __      __
|  |    |  |
|  |____|  |____
```

How can smooth waves create that?

By adding **many different frequencies**.

Start with the fundamental:

[  
\sin(\omega_0t).  
]

Shape: very round.

Add another harmonic.

Shape becomes less round.

Add another.

Sharper.

Continue adding higher frequencies.

The combined waveform gets closer and closer to the square-like target.

So a complicated shape does not require complicated basic components.

It may just require **many simple components**.

---

# 1.5 Why higher harmonics correspond to finer detail

Consider:

[  
\sin(\omega_0t)  
]

versus

[  
\sin(10\omega_0t).  
]

The second changes ten times faster.

Therefore low frequencies represent **slow/broad variation**, while high frequencies can represent **rapid/small-scale variation**.

This becomes hugely important later.

For an image:

- low spatial frequencies → smooth gradual structures
    
- high spatial frequencies → fine details, sharp edges, often noise
    

For audio:

- low frequencies → bass-like slow oscillations
    
- high frequencies → treble-like rapid oscillations
    

This helps explain why Fourier-domain filtering is so useful.

---

# 1.6 Why Fourier Series frequencies are discrete

This is a subtle but central point.

Suppose a signal has period

[  
T.  
]

Its fundamental frequency is

[  
\omega_0=\frac{2\pi}{T}.  
]

Only waves that fit an integer number of cycles into that period are compatible with the same periodicity.

Therefore the available frequencies are

[  
0,\omega_0,2\omega_0,3\omega_0,\ldots  
]

and negative counterparts.

That is why Fourier Series has a **discrete frequency spectrum**.

We draw isolated stems rather than a continuous curve:

```text
       ↑
       |
   ↑   |   ↑
   |   |   |
---|---|---|---|--- k
  -1   0   1   2
```

Later Fourier Transform will differ exactly here:

[  
\text{FS}\rightarrow\text{discrete frequency values}  
]

whereas

[  
\text{FT}\rightarrow\text{continuous frequency variable}.  
]

Lecture 7 emphasizes precisely that contrast.

---

# 1.7 One concrete example

Take

# [  
x(t)

3  
+  
2\cos(\omega_0t)  
+  
\sin(2\omega_0t).  
]

Without doing Fourier coefficient integrals, we can already say what the signal contains.

There is a DC component:

[  
3.  
]

There is a fundamental-frequency component:

[  
\omega_0.  
]

There is a second harmonic:

[  
2\omega_0.  
]

No (3\omega_0).

No (4\omega_0).

And so on.

So time domain:

[  
x(t)=3+2\cos(\omega_0t)+\sin(2\omega_0t)  
]

contains a hidden ingredient table roughly like:

|Frequency|Present?|
|---|--:|
|(0)|yes|
|(\omega_0)|yes|
|(2\omega_0)|yes|
|(3\omega_0)|no|
|(4\omega_0)|no|

The exact complex coefficients come in Module 2.

---

# 1.8 Why Fourier analysis helps solve physical systems

Your lecture uses a plucked string as one motivation.

Imagine a string with some arbitrary initial shape:

```text
       __
   ___/  \_
__/        \____
```

Trying to directly predict the motion of that weird shape may be difficult.

But suppose we decompose it:

# [  
f(x)

\text{mode}_1  
+  
\text{mode}_2  
+  
\text{mode}_3  
+\cdots  
]

Each mode is sinusoidal.

Sinusoidal vibration modes are much easier to understand.

So:

[  
\boxed{\text{break}}  
]

the complicated shape into simple modes,

then

[  
\boxed{\text{solve}}  
]

the behaviour of each mode,

then

[  
\boxed{\text{add}}  
]

them back together.

Your lecture literally presents this three-stage strategy.

---

# 1.9 Heat diffusion gives an even better frequency intuition

Imagine a metal rod whose temperature changes suddenly:

```text
HOT HOT HOT | COLD COLD COLD
```

That sharp boundary contains rapid spatial variation.

Rapid variation means significant high-frequency content.

After some time, heat diffusion smooths the temperature:

```text
hot ---- warm ---- cool
```

The sharp variations disappear.

Interpretation in Fourier terms:

> the high-frequency components decay quickly.

So instead of merely saying

“heat makes the graph smoother,”

you can say

> smoothing corresponds to suppressing high-frequency components.

That's a much more powerful idea because it generalizes to images, audio, filtering, differential equations, etc.

---

# 1.10 The graph interpretation you need to master

Suppose the Fourier coefficients look like:

```text
 a_k
  |
4 |          ↑
3 |          |
2 |      ↑   |   ↑
1 |  ↑   |   |   |   ↑
--+--|---|---|---|---|------- k
    -2  -1   0   1   2
```

You should immediately ask:

What does the stem at

[  
k=0  
]

mean?

Answer: DC/average component.

What does

[  
k=1  
]

mean?

Frequency

[  
+\omega_0.  
]

What does

[  
k=-2  
]

mean?

Frequency

[  
-2\omega_0.  
]

And if

[  
a_4=0,  
]

then there is no fourth harmonic.

This simple graph-reading skill will appear again and again.

---

# 1.11 Something extremely important: (k) is not frequency

This causes many mistakes.

The horizontal axis may be labeled:

[  
k=-2,-1,0,1,2  
]

but the actual frequencies are

[  
-2\omega_0,-\omega_0,0,\omega_0,2\omega_0.  
]

So:

[  
\boxed{k=\text{harmonic index}}  
]

while

[  
\boxed{k\omega_0=\text{actual angular frequency}}.  
]

This distinction becomes especially important in **time scaling**, because the coefficient indexed by (k) can stay the same while the actual frequency represented by that (k) changes.

---

# 1.12 One more deep intuition: Fourier Series is a coordinate system

You know a 2D point can be represented by coordinates:

[  
(3,2).  
]

Meaning:

[  
3\hat{x}+2\hat{y}.  
]

The axes are

[  
\hat{x},\hat{y}.  
]

Fourier does essentially the same thing to functions.

Instead of axes

[  
\hat{x},\hat{y},  
]

we use infinitely many axes:

[  
\ldots,  
e^{-j2\omega_0t},  
e^{-j\omega_0t},  
1,  
e^{j\omega_0t},  
e^{j2\omega_0t},  
\ldots  
]

and coordinates:

[  
\ldots,a_{-2},a_{-1},a_0,a_1,a_2,\ldots  
]

Therefore

# [  
x(t)

\sum_k a_ke^{jk\omega_0t}.  
]

This coordinate-system interpretation appears explicitly near the end of Lecture 5.

This is probably the single best conceptual model for Fourier Series.

# Module 0 + 1 checkpoint

At this point, before proceeding, you should be comfortable with these ten ideas:

1. (T) is period and (\omega_0=2\pi/T).
    
2. Periodic signals repeat.
    
3. A common fundamental frequency generates harmonics (k\omega_0).
    
4. Euler's formula converts sine/cosine into complex exponentials.
    
5. (+\omega) and (-\omega) correspond to opposite complex rotations.
    
6. (k=0) is the DC/average part.
    
7. Fourier Series decomposes a periodic signal into harmonics.
    
8. Fourier coefficients tell us **how much of each harmonic exists**.
    
9. Fourier Series spectrum is discrete because frequencies occur only at (k\omega_0).
    
10. Time domain shows the waveform; frequency domain shows its frequency ingredients.
    

The key mental picture is:

[  
\boxed{  
\text{Complicated periodic waveform}  
\quad\Longleftrightarrow\quad  
\text{list of simple frequency components}  
}  
]

and **not**

[  
\text{“Fourier Series = scary integral formula.”}  
]

The integral is only the mechanism we use to measure those ingredients.

Next should be **Module 2: Complex Exponential Fourier Series**, where we'll finally unpack

[  
x(t)=\sum_{k=-\infty}^{\infty}a_ke^{jk\omega_0t}  
]

term by term, learn how ordinary sine/cosine signals appear as (a_k)'s, and draw their frequency-domain stem plots. That is the right next step before deriving the coefficient integral.
