# Module 9: The Impulse Function

## The core idea, explained properly

Following the philosophy from Module 8, our first real task is: **find the single simplest possible signal** — something so basic that a system's response to it can serve as the "atomic building block" for understanding the response to _everything else_.

### Discrete-time impulse: $\delta[n]$

$$\delta[n] = \begin{cases} 1 & n=0 \ 0 & n \ne 0 \end{cases}$$

That's genuinely all there is to it in discrete time — a sequence that is exactly zero everywhere, except it "pokes up" to the value 1 at exactly one single instant, $n=0$. No ambiguity, no limits, no calculus subtleties — just a plain, simple, finite sequence definition. This is why discrete time is the friendlier place to _first_ build intuition for everything in this lecture (and it's also exactly what you'll be coding in Python, where sequences are just arrays — $\delta[n]$ is trivially `[..., 0, 0, 1, 0, 0, ...]`).

### Continuous-time impulse: $\delta(t)$ — the subtlety worth knowing

The slides mention $\delta(t-3)$ briefly (in the pure-delay example) without dwelling on the continuous-time impulse's technical definition — but since you'll need "basic to pro" understanding, let's make sure you know what's _actually_ different here, because it's a classic point of confusion.

You cannot simply write "$\delta(t) = 1$ at $t=0$, and $0$ elsewhere" the way you did in discrete time, because in continuous time, a function that's zero _everywhere except a single point_ has **zero width** at that point — and any reasonable function like that would just integrate to zero, contain no "area," and be physically meaningless as a "poke." Continuous time doesn't have a next sample the way discrete time does; there's no meaningful "single instant" you can assign a finite height to and have it mean anything substantial.

Instead, $\delta(t)$ (the **Dirac delta**) is defined by _what it does under integration_, not by pointwise values:

$$\int_{-\infty}^{\infty} \delta(t),dt = 1, \qquad \delta(t) = 0 \text{ for } t \ne 0$$

The intuitive picture: imagine a very tall, very thin rectangular pulse — say, height $\frac{1}{\epsilon}$ and width $\epsilon$, centered at $t=0$ (so its total area is always exactly $1$, since height × width $= \frac{1}{\epsilon}\times \epsilon = 1$, no matter how small $\epsilon$ gets). Now let $\epsilon \to 0$: the pulse becomes infinitely tall and infinitely thin, **but its area stays locked at exactly 1 forever.** That limiting object — infinitely concentrated, yet still carrying "one unit of total substance" — is $\delta(t)$. It's not really a function in the traditional sense (you can't literally evaluate "$\delta(0)$" and get a sensible finite number); it's better thought of as an idealized limit, or formally, a "distribution." For this course, you mainly need the operational picture: it's an infinitely sharp poke with total area 1, concentrated entirely at $t=0$.

This is genuinely a different mathematical object from $\delta[n]$ (which really is just an ordinary, perfectly well-defined sequence with no limiting or "infinitely thin" business involved) — but they play the _exact same conceptual role_ in their respective worlds: **the simplest possible "atomic poke" signal.**

## Why the impulse specifically (and not some other "simple" signal)?

You might reasonably ask: why not use, say, a constant signal, or a step, or a single sine wave, as the "atomic building block" instead? Here's the precise reason the impulse wins, and it connects directly back to Module 8's "Step 2":

**The impulse is the unique signal type such that _any_ other signal can be built by adding up scaled, shifted copies of it, with the scaling coefficients being simply the signal's own sample values.** You'll see this made completely explicit in Module 11 — the formula $x[n] = \sum_k x[k]\delta[n-k]$ works _precisely_ because $\delta[n-k]$ is "on" at exactly one point ($n=k$) and silent everywhere else, so stacking up scaled copies of these single-point pokes lets you reconstruct _any_ sequence's value at _every_ point independently, with no interference between different points. A constant signal, or a sine wave, doesn't have this "one point, zero everywhere else" property — you can't use _shifted copies of a sine wave_ to reconstruct an arbitrary signal's value at one isolated point without simultaneously messing up the values everywhere else. The impulse's radical concentration — "zero everywhere, one exception" — is exactly the feature that makes universal decomposition possible.

## Key properties to have crystal clear (these get used constantly from here on)

**Property 1 — Shifting where the "poke" happens:** $$\delta[n-k] = \begin{cases} 1 & n=k \ 0 & n\ne k\end{cases}$$ This is just $\delta[n]$ relocated so the single nonzero point sits at $n=k$ instead of $n=0$. Same idea as the "delay" concept from Module 3 — replacing $n$ with $n-k$ shifts the whole pattern by $k$.

**Property 2 — The sifting/sampling property (crucial, and worth stating now even though the slides use it implicitly rather than naming it):** $$x[n]\cdot\delta[n-k] = x[k]\cdot\delta[n-k]$$ Why? Because $\delta[n-k]$ is zero at every $n$ except $n=k$ — so multiplying _any_ signal $x[n]$ by $\delta[n-k]$ "kills" every value of $x[n]$ except the one at $n=k$, which survives, scaled by the impulse's height (which is 1). This tiny fact is the exact engine behind the impulse-decomposition formula in Module 11 — it's how you extract "just one sample's worth" of a signal using multiplication by a shifted impulse.

**Property 3 — Zero total "content" outside its single spike:** Trivially, $\delta[n]$ is a signal that carries no information anywhere except at one instant — this is what makes it the "purest" possible test probe for a system: when you feed it in, whatever comes out is a response to _exactly one instant of stimulation_, with no other input activity contaminating the result. That's why it's called "the system's signature" in the slides — it's the cleanest possible measurement you can make.

## The physical intuition: poking the sleeping cat

The slides' cat metaphor is worth taking seriously as intuition, not just as a joke image: think of the system as a sleeping cat, totally at rest, doing nothing. An impulse is a single, instantaneous poke — as brief and sharp as physically possible, carrying just "one unit" of stimulus, then immediately gone. Whatever the cat does _afterward_ (jump, screech, ignore it, whatever) is entirely the cat's own characteristic reaction — uncontaminated by any lingering property of the poke itself, since the poke itself had no duration, no shape, nothing to "leave a signature" of its own. This is exactly why the impulse response $h[n]$ is described as "the system's signature": you're isolating the system's _own_ intrinsic behavior, stripped of any complexity from the input, because the input itself was as featureless and pure as a signal can possibly be.

## Answers

**1.** (a) $\delta[3] = 0$ (since $3 \ne 0$). (b) $\delta[n-5]$ at $n=5$: $\delta[5-5] = \delta[0] = 1$. (c) $\sum_{n=-10}^{10}\delta[n-2]$: this sum picks up exactly one nonzero term, at $n=2$ (since $2$ is within the range $-10$ to $10$), contributing $\delta[0]=1$. So the total sum is $1$. (d) $\delta[2n]$ at $n=0$: $2(0)=0$, so $\delta[0]=1$. At $n=1$: $2(1)=2 \ne 0$, so $\delta[2] = 0$. (Note: $\delta[2n]$ is _not_ the same signal as $\delta[n]$ — it's only nonzero when $2n=0$, i.e., only at $n=0$, same single spike location as $\delta[n]$ in this particular case — but be careful in general: this kind of "argument scaling" is exactly the kind of operation that was shown to be time-_varying_ back in Module 3, so don't assume scaling the argument is ever "harmless.")

**2.** (a) The sifting property tells us $\sum_n x[n]\delta[n-4]$ collapses to just $x[4]$ (the one surviving term, at $n=4$). Here $x[n]=n^2-1$, so $x[4] = 16-1=15$. **Answer: 15.** (b) $\delta[n+1] = \delta[n-(-1)]$, so the surviving term is at $n=-1$. Evaluate $(3n+2)$ at $n=-1$: $3(-1)+2 = -3+2=-1$. **Answer: −1.**

**3.** The student's error is treating $\delta(0)$ as if it were an ordinary (even if very large) finite number that you could multiply by a width to get area — but $\delta(t)$ is **not defined by pointwise values at all**; it's defined by its integral/area property. The entire point of the Dirac delta construction (the shrinking-rectangular-pulse limit) is that height and width shrink/grow _together_ in a precisely balanced way so that **height × width stays fixed at exactly 1**, no matter how the limit is taken — it is never a case of "an infinite height times a fixed width," which would indeed be a meaningless infinity, but rather "height that grows in exact inverse proportion to a width that shrinks," so the product is constant. There's no well-defined finite number "$\delta(0)$" to multiply by 2 in the first place — that step is invalid from the start.

The correct property to invoke is simply: since **all** of $\delta(t)$'s "area" (the full amount, $=1$) is concentrated at $t=0$, and the interval $[-1,1]$ contains the point $t=0$ entirely within its range (not touching the boundary), the _entire_ unit of area is captured within this interval, regardless of how much wider than "necessary" the interval is: $$\int_{-1}^{1}\delta(t),dt = 1$$ (In general, $\int_{a}^{b}\delta(t),dt = 1$ for _any_ interval $[a,b]$ that contains $t=0$ strictly inside it, and $=0$ for any interval that doesn't contain $0$ at all.)

**4.** The reason $\delta[n]$ (not $u[n]$) is the _natural_ fundamental building block is specifically because of the **sifting/decomposition property** established in Property 2 above and about to be used explicitly in Module 11: _any_ arbitrary signal $x[n]$ can be written, with no exceptions and no approximation, as a sum of scaled, shifted copies of $\delta[n]$ alone: $$x[n] = \sum_k x[k],\delta[n-k]$$ This works because $\delta[n-k]$ is "on" at exactly one isolated point and silent everywhere else, so each term in the sum contributes to _exactly one_ sample of $x[n]$ without disturbing any other sample — the impulse's radical concentration at a single point is precisely what lets you assemble an arbitrary signal value-by-value, independently, at every point.

$u[n]$ does **not** have this same "isolated single point" structure — it's on at $n=0$ _and stays on forever afterward_. While it's true (as a more advanced fact, not covered in these slides in depth) that you _can_ alternatively decompose signals using differences of shifted steps, and you _can_ characterize an LTI system using its step response instead of impulse response, doing so requires an _extra layer_ of manipulation (differencing) precisely _because_ $u[n]$ isn't the "atomic," single-point building block — you'd first have to break $u[n]$-based pieces back down into impulse-like differences anyway to get the same clean, one-point-at-a-time reconstruction property. So while $u[n]$ is a perfectly legitimate _test signal_ you could use to characterize a system, it's not the most _primitive_ building block — $\delta[n]$ is strictly simpler and more fundamental, since it alone has the "one point, zero elsewhere" property that makes universal signal decomposition immediate and exception-free.
