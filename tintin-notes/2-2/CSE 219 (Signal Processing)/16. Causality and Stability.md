# Module 16: Causality and Stability

## Setting up the big picture: two independent "sanity checks" on a system

We've spent 15 modules building the machinery to compute what a system _does_ (its output, via convolution). Now we ask a different kind of question: given a system's impulse response $h[n]$ (or $h(t)$), can we tell, just by _looking_ at it, whether the system is physically realizable and well-behaved? Two properties matter here, and — just like linearity and time-invariance back in Modules 2–4 — **they are completely independent of each other.** A system can be any combination: causal-and-stable, causal-but-unstable, non-causal-but-stable, or neither. We'll see worked examples of exactly this independence below.

## Causality: "no time travel"

### The definition, and why it's about the _system_, not the input

A system is **causal** if its output at any time $n_0$ depends _only_ on input values at times $n \le n_0$ — the present and the past, never the future. Intuitively: the system can't react to something that hasn't happened yet. Every physical system you interact with in real life (a speaker, a car's suspension, a filter circuit) is forced to be causal, because reality doesn't let effects precede their causes. Non-causal systems _can_ exist mathematically (and are perfectly useful in offline signal/image processing, where you have the _entire_ recorded signal available in memory before you start computing) — but they can't exist as real-time physical hardware, since that would require literally seeing the future.

### The test, derived from what you already know

Here's the beautiful part: because of everything we built in Modules 9–13, you don't need to reason about "the system's response to arbitrary inputs" to check causality — you only need to look at $h[n]$, the impulse response, and ask **when did the impulse response's nonzero part begin?**

Recall from Module 10, Example 3, and Module 12, Exercise 2: the impulse response $h[n]$ is literally the system's reaction to a poke that happens at $n=0$. If $h[n]$ has any nonzero value at some negative index (say $h[-3] \ne 0$), that means the system produced a nonzero _reaction_ three time-steps **before** the poke that caused it even happened. That's a direct violation of causality — you'd be watching the reaction _before_ the cause.

$$\textbf{Discrete-time:} \quad \text{causal} \iff h[n] = 0 \text{ for all } n<0$$ $$\textbf{Continuous-time:} \quad \text{causal} \iff h(t) = 0 \text{ for all } t<0$$

This test is exactly what it looks like: **check whether the impulse response's "clock" starts at or after zero.** If any nonzero content appears before the poke, the system is non-causal — full stop, no further calculation needed.

## Stability: "bounded input, bounded output" (BIBO)

### The definition, in plain terms

A system is **BIBO stable** if every bounded input produces a bounded output — i.e., if you promise the input signal never exceeds some fixed ceiling $B$ (in either direction: $|x(t)|\le B$ for all $t$), the system guarantees the output also never blows up to infinity; it stays capped at some finite ceiling too. An _unstable_ system is one where some perfectly reasonable, bounded input can still make the output run away to infinity — clearly a disaster for any real device (imagine an amplifier where a normal-volume input signal causes the output to scream off to infinite voltage).

### Deriving the test (worth actually seeing, not just memorizing)

Start from the convolution formula and use a basic inequality — the triangle inequality plus the fact that $|x(t-\tau)|\le B$ for _every_ $\tau$, since we assumed the input is bounded everywhere:

$$|y(t)| = \left|\int_{-\infty}^{\infty} h(\tau)x(t-\tau),d\tau\right| \le \int_{-\infty}^{\infty} |h(\tau)|,|x(t-\tau)|,d\tau \le B\int_{-\infty}^{\infty}|h(\tau)|,d\tau$$

Look at what this says: **the output's size is capped by (the input's bound) times (the total area under $|h(t)|$).** If that total area is some finite number, then no matter how the bounded input wiggles around, the output can never exceed $B$ times that finite number — bounded input truly guarantees bounded output. But if that area is _infinite_, this bound is useless — nothing stops the output from growing without limit for a cleverly chosen (but still perfectly legitimate, bounded) input.

$$\textbf{Discrete-time:} \quad \text{stable} \iff \sum_{n=-\infty}^{\infty}|h[n]| < \infty$$ $$\textbf{Continuous-time:} \quad \text{stable} \iff \int_{-\infty}^{\infty}|h(t)|,dt < \infty$$

**The physical intuition:** stability is about the _impulse response eventually dying out_ (or, if it doesn't die out, at least not accumulating infinite total "energy"). Recall Module 10's echo systems: $h[n]=\alpha^n u[n]$ with $0<\alpha<1$ is stable (finite total area, since it's a convergent geometric series), while $h[n]=u[n]$ (undamped echoes forever) sits right at the boundary — its sum $\sum|u[n]| = 1+1+1+\cdots$ diverges, so it is **not** stable. This matches physical intuition perfectly: a room where echoes never fade at all would let you clap once and have the sound energy build up without bound if you kept clapping — clearly unphysical, and exactly what the math flags as unstable.

## Two elegant proofs: periodicity kills both causality and stability (unless $h=0$)

These are genuinely clever "two birds, one stone" arguments, worth understanding rather than memorizing, because the _style_ of reasoning (proof by contradiction, using an infinite repeating structure to force a contradiction) reappears throughout signals theory.

### Claim 1: A causal system cannot have a nonzero periodic impulse response

**Proof by contradiction.** Suppose $h(t)$ is periodic with period $T$, and suppose it's nonzero _somewhere_ at some positive time — say $h(t_0)\ne 0$ for some $t_0>0$. Because $h$ is periodic, that exact same nonzero value must repeat at every shift by a multiple of the period: $$h(t_0) = h(t_0-T) = h(t_0-2T) = h(t_0-3T) = \cdots$$ Now here's the trap: no matter how large $t_0$ is, if you keep subtracting $T$ (a fixed positive number) enough times, **you will eventually land on a negative time.** Formally, choose $k$ large enough that $t_0 - kT < 0$. But we just showed $h(t_0-kT)$ must equal the same nonzero value $h(t_0)$ — so $h$ is nonzero at a negative time. That directly **contradicts** causality (which demands $h(t)=0$ for all $t<0$). The only way to avoid this contradiction is if $h(t_0)$ was $0$ to begin with — meaning $h$ can't be nonzero _anywhere_ on the positive side either, without eventually forcing a violation. So the only impulse response that can be both causal and (nontrivially) periodic is the trivial one, $h(t)\equiv 0$.

### Claim 2: A stable system cannot have a nonzero periodic impulse response

**Proof by contradiction, same flavor.** Suppose $h(t)$ is periodic with period $T$ and nonzero somewhere within one period, so that $\int_{\text{one period}}|h(t)|,dt = A$ for some $A>0$. Since $h$ repeats identically in _every_ period, forever (both forward and backward in time, since periodicity has no starting or stopping point), the total area under $|h(t)|$ across all of time is: $$\int_{-\infty}^{\infty}|h(t)|,dt = \cdots + A+A+A+\cdots = \infty$$ This is an infinite sum of the _same_ positive number $A$, repeated infinitely many times (both because time stretches to $+\infty$ and to $-\infty$) — it diverges. This directly violates the stability test (finite total area required), so a nonzero periodic $h(t)$ can never be stable either.

**The shared insight behind both proofs:** periodicity means "the same behavior repeats forever, with no beginning and no end." But causality requires the impulse response to have a definite _starting point_ (silence before $t=0$), and stability requires it to _eventually settle down_ (finite total contribution) — both of these are fundamentally incompatible with a pattern that repeats identically forever in both directions. This is why, physically, oscillators and resonators (systems whose natural impulse response looks periodic/sinusoidal) always need some damping or decay mixed in to be realistic — a "pure," undamped periodic response is a mathematical idealization that violates both properties simultaneously.

## Worked practice: classifying two impulse responses fully

### System 1: $h_1(t) = e^{2t}u(-2-t)$

**First, find the support** — where is $u(-2-t)$ equal to 1? We need $-2-t\ge 0$, i.e., $t \le -2$. So $h_1(t)$ is nonzero only for $t\le -2$ — a left-sided signal that lives entirely in the far past (relative to $t=0$), never touching $t\ge -2$ at all.

**Causality test:** since $h_1(t)$ is nonzero at, e.g., $t=-3$ (a negative time), it directly violates $h(t)=0$ for $t<0$. **Not causal.** (Intuitively: this system reacts to a poke by producing a response that supposedly already happened at least 2 time-units _before_ the poke — obviously non-physical, but a fine mathematical/theoretical exercise.)

**Stability test:** compute the total area: $$\int_{-\infty}^{\infty}|h_1(t)|,dt = \int_{-\infty}^{-2} e^{2t},dt = \left[\tfrac12 e^{2t}\right]_{-\infty}^{-2} = \tfrac12 e^{-4} - 0 = \tfrac12 e^{-4}$$ This is a small, finite number. **Stable.**

**So System 1 is: not causal, but stable** — a concrete demonstration that these two properties really are independent; you can fail one while passing the other.

### System 2: $h_2(t) = te^{-t}u(t)$

**Support:** $u(t)=1$ for $t\ge 0$, so $h_2(t)$ is nonzero only for $t\ge 0$.

**Causality test:** $h_2(t)=0$ for all $t<0$ (directly, since $u(t)$ kills everything before $t=0$). **Causal.**

**Stability test:** $$\int_{-\infty}^{\infty}|h_2(t)|,dt = \int_0^\infty t e^{-t},dt$$ This is a standard integral (integration by parts, or recognize it as the Gamma function $\Gamma(2)=1!=1$): $\int_0^\infty te^{-t}dt = 1$. Finite. **Stable.**

**So System 2 is: causal and stable** — the "well-behaved, physically realizable" combination.

## Worked practice: minimum delay for causality

**Problem:** $x(t) = e^{-2t}u(t+2)$ — nonzero starting at $t=-2$ (since $u(t+2)=1$ for $t\ge -2$). Define $y(t) = x(t-a)$ (a pure delay by $a$). Find the minimum $a$ that makes $y(t)$ causal.

**Reasoning:** $y(t) = x(t-a)$ is nonzero wherever $x$'s argument $(t-a)$ satisfies $x$'s own condition for being "on" — i.e., where $t-a \ge -2$, i.e., $t \ge a-2$. For $y(t)$ to be causal, we need $y(t)=0$ for all $t<0$ — meaning $y$'s "switch-on point," $a-2$, must be at or after $t=0$: $$a - 2 \ge 0 \implies a \ge 2$$

**Minimum delay: $a=2$.** Intuition: the original signal $x(t)$ starts "early" — 2 time units before $t=0$. To make it causal (start at or after $t=0$), you must delay it by at least enough to cancel out that head start — exactly 2 units. Delaying by less than 2 still leaves some nonzero content sitting before $t=0$; delaying by exactly 2 shifts the start precisely onto $t=0$ (the boundary case, still technically causal since the condition is $\ge 0$ for the switch-on point, meaning $h(t)=0$ strictly for $t<0$ is preserved).

## Answers

**1.** First find the support: $u[n+1]=1$ for $n\ge -1$, so $h[n]$ is nonzero starting at $n=-1$.

**Causality:** $h[-1] = \left(\tfrac13\right)^{-1} = 3 \ne 0$, and $-1<0$ — nonzero at a negative index. **Not causal.**

**Stability:** $$\sum_{n=-\infty}^{\infty}|h[n]| = \sum_{n=-1}^{\infty}\left(\tfrac13\right)^n = 3 + 1+\tfrac13+\tfrac19+\cdots = \frac{3}{1-1/3} = \frac{3}{2/3}=4.5$$ (Geometric series starting at $n=-1$ with ratio $1/3$: first term is $(1/3)^{-1}=3$, sum $=\dfrac{\text{first term}}{1-\text{ratio}}=\dfrac{3}{1-1/3}$.) Finite. **Stable.**

So: **not causal, but stable.**

**2.** Support: $u(t)=1$ for $t\ge0$, so $h(t)$ nonzero only for $t\ge0$.

**Causality:** $h(t)=0$ for $t<0$. **Causal.**

**Stability:** $$\int_{-\infty}^{\infty}|h(t)|,dt = \int_0^\infty e^{3t},dt = \left[\tfrac13 e^{3t}\right]_0^\infty = \infty$$ The exponential is _growing_ ($e^{3t}$, positive exponent), so the integral diverges — the total area is infinite. **Not stable.**

So: **causal, but not stable** — the mirror-image case to Systems 1 and 2 from the worked examples, showing all four combinations really are possible (this one: causal-but-unstable; System 1 above: not-causal-but-stable; System 2: causal-and-stable; and Exercise 3 below will give you the fourth combination).

**3.** $h[n]=5\cos(\pi n)$ is nonzero (it equals $5$ at even $n$, $-5$ at odd $n$ — never actually zero) and clearly periodic (period 2 in $n$, since $\cos(\pi(n+2))=\cos(\pi n + 2\pi) = \cos(\pi n)$).

By the discrete-time analog of **Claim 1** (causality vs. periodicity): since $h[n]$ is periodic and nonzero, the same nonzero value must repeat backward indefinitely — including at negative indices — directly violating causality's requirement that $h[n]=0$ for $n<0$. **Not causal.**

By the discrete-time analog of **Claim 2** (stability vs. periodicity): since $h[n]$ is periodic and never actually decays to zero (it just keeps alternating $5,-5,5,-5,\dots$ forever in both directions), the sum $\sum|h[n]|$ adds up infinitely many copies of $|{\pm}5|=5$, which diverges. **Not stable.**

So: **neither causal nor stable** — the fourth and final combination, and a clean illustration of exactly why the two "periodicity kills X" proofs from this module are useful shortcuts: you get _both_ conclusions instantly, with zero integration or summation required, just by recognizing the periodic structure.

**4.** Find where each individual term needs its own delay to become causal.

**Term 1:** $x(t-a) = e^{-(t-a)}u(t-a+5)$. This switches on where $t-a+5\ge 0$, i.e., $t\ge a-5$. For causality (switch-on at or after $t=0$): need $a-5\ge 0 \Rightarrow a\ge 5$.

**Term 2:** $x(t-a-3) = e^{-(t-a-3)}u(t-a-3+5) = e^{-(t-a-3)}u(t-a+2)$. Switches on where $t\ge a-2$. For causality: need $a-2\ge0 \Rightarrow a\ge 2$.

**Both conditions must hold simultaneously** (the _sum_ $y(t)$ is causal only if _every_ individual piece contributing to it is causal — if even one piece has nonzero content before $t=0$, the sum will too, since the other term can't "cancel out" a nonzero value at a specific point in general). The **binding** (stricter) constraint is the larger requirement: $a\ge 5$ (since $a\ge5$ automatically also satisfies $a\ge2$, but not vice versa).

**Minimum delay: $a=5$.** Intuition: Term 1 is the "more delayed-needing" piece (it has an _earlier_ natural start time before shifting, since it isn't given the extra +3 head start that Term 2 gets) — so it's the bottleneck that determines how much total delay the whole sum needs before every piece is safely causal.

# Module 18: Causality/Stability on Split & "Trick" Exponentials (CT2 Q2 style)

## The trap this module exists to defuse

Your actual CT2 Question 2 is: $$h[n] = -\left(\tfrac12\right)^n u[n] + (1.01)^n u[1-n]$$

The instinctive (and wrong) reaction most students have: _"$1.01 > 1$, so that term grows forever, so the system must be unstable."_ This module exists specifically to show you why that instinct is dangerously incomplete — and to give you a rule that never fails you.

## The rule you actually need: direction matters as much as the base

Go back to Module 10's intuition: whether a geometric term $a^n$ "blows up" or "dies out" depends on **which direction you're summing it**, not just whether $|a|$ is bigger or smaller than 1. Let's derive both cases side by side, since seeing them together is what makes the rule click permanently.

**Right-sided exponential, $a^n u[n]$ (nonzero for $n\ge 0$, stretching toward $+\infty$):** $$\sum_{n=0}^{\infty} |a|^n = 1+|a|+|a|^2+\cdots$$ This is a standard geometric series **converges iff $|a| < 1$.** If $|a|\ge 1$, each successive term is the same size or bigger, so the sum runs away to infinity.

**Left-sided exponential, $a^n u[-n]$ or similar (nonzero for $n\le$ some fixed point, stretching toward $-\infty$):** $$\sum_{n=-\infty}^{0}|a|^n = \cdots + |a|^{-2}+|a|^{-1}+1$$ Substitute $m=-n$ (so $m=0,1,2,\dots$ as $n=0,-1,-2,\dots$): this becomes $\sum_{m=0}^\infty |a|^{-m} = \sum_{m=0}^\infty \left(\tfrac{1}{|a|}\right)^m$, which **converges iff $\dfrac{1}{|a|}<1$, i.e., iff $|a|>1$.**

## The rule, stated as a clean table (memorize this — it's the whole trick)

|Signal shape|Converges (finite sum) when...|
|---|---|
|$a^n u[n]$ — **right**-sided|$\lvert a \rvert < 1$|
|$a^n u[-n]$ (or $u[c-n]$, any left-sided variant)|$\lvert a \rvert > 1$|

**The intuition that makes this permanently obvious, not just memorized:** a right-sided signal marches off toward $n=+\infty$ — for its total "area" to stay finite, each successive term must be _shrinking_ ($|a|<1$). A left-sided signal marches off toward $n=-\infty$ — but since it's $a^n$ with $n$ getting _more and more negative_, that's the same as $\frac{1}{a^{|n|}}$ growing in the denominator, so for the _terms themselves_ to shrink as you head toward $-\infty$, you need $|a|>1$ (a "big" base, when raised to increasingly negative powers, produces increasingly _tiny_ values). **A left-sided signal built from a "large" base is not a contradiction — it's actually required for that piece to decay in the direction it's heading.**

This is _exactly_ what's happening in your exam question: $(1.01)^n u[1-n]$ is left-sided (support $n\le 1$), and its base ($1.01$) is bigger than 1 — which, according to the rule, is precisely the condition for **convergence**, not divergence. The "$1.01>1$ looks scary" instinct has the direction backwards.

## Full worked solution: your actual CT2 Question 2

$$h[n] = -\left(\tfrac12\right)^n u[n] + (1.01)^n u[1-n]$$

### Step 1 — identify the support of each piece

- Term A: $-\left(\tfrac12\right)^n u[n]$ — nonzero for $n\ge 0$ (right-sided).
- Term B: $(1.01)^n u[1-n]$ — $u[1-n]=1 \iff 1-n\ge 0 \iff n\le 1$ (left-sided).

Note these two pieces **overlap** at $n=0,1$ — both terms are simultaneously active there. That's fine; we just add them at those points.

### Step 2 — Causality test

We need $h[n]=0$ for **all** $n<0$. Check Term B at, say, $n=-5$: $(1.01)^{-5}u[1-(-5)] = (1.01)^{-5}\cdot u[6] = (1.01)^{-5}\cdot 1 \approx 0.951 \ne 0$.

So $h[n]$ is nonzero at negative indices. **Not causal.**

_(Term A alone would have been causal on its own — it's Term B, the left-sided piece, that breaks causality. This is worth noticing: causality is decided by the piece with the "wrong-direction" support, regardless of what the other piece does.)_

### Step 3 — Stability test

Compute $\sum_n |h[n]|$. Since the two pieces overlap only at 2 points ($n=0,1$), it's cleanest (and perfectly rigorous, via the triangle inequality $|A+B|\le|A|+|B|$) to bound the total by summing $|{\rm Term\ A}|$ and $|{\rm Term\ B}|$ separately — if _both_ pieces individually have finite total area, the combined signal is guaranteed stable too.

**Term A:** $\displaystyle\sum_{n=0}^\infty \left(\tfrac12\right)^n = \frac{1}{1-1/2} = 2$ — finite (right-sided, base $1/2<1$ ✓ matches the rule).

**Term B:** $\displaystyle\sum_{n=-\infty}^{1}(1.01)^n$. Substitute $m=1-n$ (so $m=0,1,2,\dots$ as $n=1,0,-1,\dots$), giving $n=1-m$: $$\sum_{m=0}^{\infty}(1.01)^{1-m} = 1.01\sum_{m=0}^\infty\left(\tfrac{1}{1.01}\right)^m = 1.01\cdot\frac{1}{1-\frac{1}{1.01}} = 1.01 \cdot \frac{1.01}{0.01} = \frac{1.01^2}{0.01} = 102.01$$ Finite (left-sided, base $1.01>1$ ✓ matches the rule).

**Total:** $\sum_n|h[n]| \le 2 + 102.01 = 104.01 < \infty$. **Stable.**

### Final answer: **not causal, but stable**

This is precisely the trap the exam is testing: a term with base $>1$ _looks_ alarming, but because it's paired with the _left_-facing step $u[1-n]$ rather than the right-facing $u[n]$, it actually converges beautifully — it's the _causality_ that fails here, not the stability, which is the exact opposite of what a rushed "big base = unstable" instinct would predict.

## Answers

**1.** Support: $u[-n-1]=1\iff -n-1\ge0 \iff n\le -1$ — left-sided. Base is $3>1$. By the table: **left-sided + base $>1$ → predict convergence (stable).**

**Causality:** nonzero at, e.g., $n=-2$: $3^{-2}=1/9\ne0$. **Not causal** (nonzero at negative index — in fact its _entire_ support is at negative indices here).

**Stability:** $\sum_{n=-\infty}^{-1}3^n$. Let $m=-1-n$ ($m=0,1,2,\dots$ as $n=-1,-2,\dots$), $n=-1-m$: $\sum_{m=0}^\infty 3^{-1-m} = \tfrac13\sum_{m=0}^\infty (1/3)^m = \tfrac13\cdot\tfrac{1}{1-1/3}=\tfrac13\cdot\tfrac32=\tfrac12$. Finite. **Stable.** ✓ Matches the prediction.

**2.** Term A: $\left(\tfrac15\right)^n u[n]$ — right-sided, base $1/5<1$. Term B: $2^n u[-n-4]$ — support: $u[-n-4]=1\iff n\le -4$, left-sided, base $2>1$.

**Causality:** Term B is nonzero at negative indices (its entire support is $n\le-4$, all negative) — **breaks causality**. Term A alone would be causal, but since Term B is present, the whole $h[n]$ is **not causal.**

**Stability:** Term A: $\sum_{n=0}^\infty(1/5)^n = \dfrac{1}{1-1/5}=\dfrac54$ — finite (right-sided, base$<1$ ✓ matches table). Term B: $\sum_{n=-\infty}^{-4}2^n$; let $m=-4-n$, $n=-4-m$: $\sum_{m=0}^\infty 2^{-4-m} = 2^{-4}\sum_{m=0}^\infty(1/2)^m = \tfrac{1}{16}\cdot 2 = \tfrac18$ — finite (left-sided, base$>1$ ✓ matches table). Total: finite + finite = finite. **Stable.**

So: **not causal, but stable** — same overall verdict shape as the actual CT2 Q2, good practice for recognizing the pattern.

**3.** Support: $u[n-2]=1\iff n\ge2$ — right-sided, starting at $n=2$ (not $n=0$). Base $1/3<1$, so by the convergence table this will certainly be stable (right-sided, small base) — **but causality is a separate, more basic question that doesn't even need the exponential's value.**

**Causality:** we need $h[n]=0$ for all $n<0$. Since the support only begins at $n=2$ (which is $\ge 0$), $h[n]$ is automatically zero for every $n<0$ (in fact, it's even zero at $n=0,1$ too — just not needed for causality specifically). **Causal.** ✓

The point of this exercise: **causality only cares about the sign of the index where the support begins — it has nothing to do with the base of the exponential at all.** A small, "safe-looking" base doesn't cause a causality problem, and a scary-looking base (like Exercise 1 or 2) doesn't automatically cause one either — the _only_ thing that matters for causality is whether _any_ nonzero content sits at negative $n$, full stop.

**4.** The claimed shortcut ("base $>1$ automatically means unstable") is directly disproven by the worked CT2 Q2 example: the term $(1.01)^n u[1-n]$ has base $1.01>1$, yet the _system as a whole is stable_ — the stability sum for that term converges to a perfectly finite value ($102.01$), because the term is **left-sided** ($u[1-n]$, support $n\le1$), not right-sided.

The correct one-question check to replace the flawed shortcut: **"Which direction is this term's support facing — right ($u[n-c]$, stretching toward $+\infty$) or left ($u[c-n]$, stretching toward $-\infty$)?"** Only _after_ answering that question does the base's size become meaningful: right-sided needs base $<1$ to converge; left-sided needs base $>1$ to converge. Seeing "base $>1$" in isolation, without first checking which direction the term is facing, tells you nothing reliable at all — as this module's whole running example demonstrates.
